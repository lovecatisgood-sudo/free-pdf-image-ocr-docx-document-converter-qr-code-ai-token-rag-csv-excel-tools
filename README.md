## Why these tools

- **Private by default:** supported file processing happens in browser memory.
- **No account:** the tools work without registration or a subscription.
- **No watermark:** generated output is not branded with an output watermark.
- **Bilingual:** Thai and English routes are part of the same codebase.
- **Fork-friendly:** analytics are disabled unless a deployer explicitly configures them.
- **Permissive:** commercial use, modification, and redistribution are allowed under MIT.

## Requirements

- Node.js 22.13 or newer is recommended for the complete collection.
- npm with lockfile support.

## Install all projects

```bash
git clone https://github.com/lovecatisgood-sudo/free-pdf-image-ocr-docx-document-converter-qr-code-ai-token-rag-csv-excel-tools.git
cd free-pdf-image-ocr-docx-document-converter-qr-code-ai-token-rag-csv-excel-tools
npm run setup
```

Each application has its own lockfile. The root command runs `npm ci` in every application directory.

## Run a project locally

```bash
# QR Generator
npm run dev --prefix DJayTools-Free-QR-Generator-Source

# Image Tools
npm run dev --prefix djai-image-resizer

# PDF Tools
npm run dev --prefix djai-pdf-tools

# Document, AI, and Spreadsheet Tools
npm run dev --prefix djai-document-tools
```

The applications retain their DJAI production subpaths:

- `/tools/qrgen`
- `/tools/resizeimg`
- `/tools/PDFTools`
- `/tools/document`, `/tools/ai`, and `/tools/spreadsheet`

If your deployment uses different paths or branding, follow [CUSTOMIZING.md](CUSTOMIZING.md).

## Build, lint, and test

```bash
npm run build
npm run lint
npm test
```

The root runner executes each supported command across the four applications. GitHub Actions performs clean installs and project-specific checks.

## Privacy and analytics

File transformations run locally in the browser. A deployment still receives ordinary requests for HTML, JavaScript, styles, fonts, and images. A fork can also change the privacy model, so review the deployment you actually use.

Google Analytics is disabled in this distribution unless `NEXT_PUBLIC_GA_ID` is set during a Next.js build:

```bash
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX npm run build
```

Review your own privacy and cookie obligations before enabling analytics or adding remote services.
