# Changelog

All notable changes to the open-source distribution will be documented here.

The format is based on Keep a Changelog, and releases should use semantic versioning when versioned packages are published.

## [Unreleased]

### Added

- Initial MIT-licensed open-source distribution.
- QR, image, PDF, document, AI-context, and spreadsheet tools.
- Bilingual Thai and English pages.
- Community health files, CI, security policy, and optional attribution guide.
- English and Thai repository guides, a verified live-demo directory, roadmap, and launch checklist.

### Changed

- Removed default hard-wired analytics from forks.
- Normalized package metadata and independent build commands.
- Replaced the provisional brand-first name with the search-intent-first title `Free PDF, Image, OCR & Document Converter Tools`.
- Updated Next.js and vulnerable transitive build dependencies to patched releases identified during the launch audit.
