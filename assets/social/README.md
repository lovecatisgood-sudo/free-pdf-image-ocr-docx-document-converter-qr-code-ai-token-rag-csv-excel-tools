# Social-media logo assets

This directory contains web-optimized copies of official Facebook, Instagram, and X logo files supplied by the repository maintainer from the platforms' brand kits. The source artwork is intentionally not modified beyond proportional resizing and PNG optimization.

The logos are used only as visual links to Siamese Cat Dev social profiles. They remain trademarks of their respective owners, are not covered by this repository's MIT License, and do not imply platform sponsorship or endorsement. See [TRADEMARKS.md](../../TRADEMARKS.md).

| `instagram.png` | Link to `@djcatdev` on Instagram |
| `x.png` | Link to `@siamesecatdev` on X |
