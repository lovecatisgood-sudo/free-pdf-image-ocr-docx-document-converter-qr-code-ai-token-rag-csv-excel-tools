## Naming rationale

The repository name and H1 begin with the highest-value user tasks: PDF, image, OCR, and document conversion. QR, AI token/RAG, CSV, and Excel appear immediately in the description and first README paragraph. DJAI Academy and Siamese Cat Dev appear as the creator attribution rather than occupying the highest-value title words.

The selected 79-character slug is within GitHub's 100-character repository-name limit and places every major feature family directly in the repository URL.

Do not replace it with a vague brand-only or generic title. Do not extend the slug with every individual conversion because that becomes difficult to read and resembles keyword stuffing.
