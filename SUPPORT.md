# Support

## Questions and help

- Use GitHub Discussions for usage questions, deployment ideas, and community examples when Discussions are enabled.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Include the tool, route, browser, operating system, input format, and reproduction steps.
- Use synthetic files. Never upload confidential or personal documents to an issue.

## What maintainers can provide

This is community-supported software. Maintainers may help with defects in the checked-in source but cannot guarantee response times, custom integrations, hosting support, data recovery, or compatibility with every document and browser.

For commercial development or partnership enquiries, contact `contact@djai.academy` or visit [Siamese Cat Dev](https://www.djai.academy/siamese_cat/dev/en/).
